## 第 1–2 步：先弄懂概念

- 一次请求 = 网址 + 参数；返回 = 一段 JSON + 一个三位数状态码。
- 200 正常，403 不许进，404 没有这个路径。
- token 就是通行证。access token 5 分钟失效，refresh token 用来换新的。

## 第 3 步：骨架 + 第一个接口

### 骨架怎么来的

- 浏览器打开 start.spring.io：Maven / Java 21 / Spring Boot 4.1.2 / 依赖选 Spring Web，生成 zip，解压到 `labs/` 下。
- `./mvnw` 是项目自带的 Maven，不用另装。第一次跑会先下载 Maven 和依赖，慢是正常的。
- 骨架里没有任何业务代码，只有 `pom.xml`、`mvnw`、一个启动类。

### 目录各干什么

| 位置 | 作用 |
|---|---|
| `pom.xml` | 采购清单：要哪些库、什么版本、Java 几 |
| `mvnw` + `.mvn/` | 自带的 Maven，梯子 |
| `src/main/java/` | 写代码的地方，所有类都在这里 |
| `src/main/resources/application.properties` | 项目配置，一行一项（端口、数据库地址……） |
| `src/main/resources/static/` | 图片、CSS 这类静态文件 |
| `src/test/java/` | 测试代码，`./mvnw test` 跑它 |
| `target/` | 编译产物，可整个删掉，别手改 |

真正要关心的只有三个：`pom.xml`、`src/main/java`、`application.properties`。

### 第一个接口

`HelloController.java` 里：

- 类上 `@RestController`：这个类是前台，负责接网址；方法 return 的字符串直接写回浏览器。
- 方法上 `@GetMapping("/hello")`：用 GET 访问 `/hello` 就跑这个方法。

访问 `http://localhost:8080/hello` → `Hello, World!`，状态码 200。

### 踩过的坑

- 注解标红 = 缺 import。VSCode 里光标停在红字上按 `⌘ .` 补上。
- 还没写接口时，访问根路径返回 404 是正常的：服务起来了，只是没有这个路径。
- 类必须放在 `com.example.jwt_lab` 包（或子包）下。启动类上的 `@SpringBootApplication` 只扫自己所在的包往下，放外面就找不到，接口 404。

## 第 4 步：`/login`（进行中）

- 目标：`/login?username=admin&password=admin123` 返回一串随机字符（36 位，像 `3f6a9c1e-8b2d-4f71-9a0c-2d5e7b1f4a83`）；密码错返回「账号或密码错误」。
- 新东西：`@RequestParam` 去网址 `?` 后面按名字取参数；`UUID.randomUUID().toString()` 生成随机串（`import java.util.UUID;`）。
- 坑：`@RequestParam` 默认必填，网址少参数会 400。字符串比较用 `"admin".equals(username)`，别用 `==`。

## 疑问记录

### Spring Boot 这些文件夹都干什么用？

见上面「目录各干什么」。核心是三个：`pom.xml` 说清楚要什么库，`src/main/java` 放代码，`application.properties` 放配置。`target/` 是编译产物，删了会重新生成。

### `@RestController` 和 `@GetMapping` 是干什么的？

注解是贴在类或方法上的标签，Spring 启动时扫一遍才知道怎么处理。

- `@RestController`：贴类上，说明这个类负责接网址，返回的内容直接写进响应体，不当网页去找。
- `@GetMapping("/hello")`：贴方法上，说明 GET 访问 `/hello` 时执行这个方法。

合起来读：这个类当前台 → 收到 `/hello` 的 GET → 交给这个方法 → 它返回的字符串原样写回浏览器。

### 为什么 java 文件夹要分这么多层包？

`com/example/jwt_lab` 不是三个包，是一个包名被斜杠展开。类全名是 `com.example.jwt_lab.HelloController`。

- 包名 = 反写域名 + 项目名，保证全世界两个 `HelloController` 不撞车。
- 包必须和文件夹一一对应，对不上编译不过——这是 Java 的规矩，不是 Spring 的。
- 包名不能有横杠，所以 Artifact 填 `jwt-lab`，Initializr 给了 `jwt_lab`。

### 这个包能干啥？

包本身不干活，它只是架子。作用三个：给类一个位置、防重名、划范围（Spring 只扫启动类所在包以下）。

能力在类和方法里。另外同一个包里不写 `public` 的类和方法只有同包能看见，叫「包内可见」；目前都写的 `public`，用不上。
