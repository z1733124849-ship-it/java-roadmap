# 学习清单（2026-11-14 起，四周）

每天 1–2 小时。规则：**看 30 分钟，动手 30 分钟**。只看不动手，等于没看。

检验方式：每节看完，用自己的话讲一遍给我（讲什么、为什么需要、不用会怎样），我出两道题。讲不清就重看那一节。

---

## 第 1 周：Java 基础（3 天，每天 90 分钟）

**主课**：尚硅谷 宋红康《Java 入门视频教程》
<https://www.bilibili.com/video/BV1Kb411W75N>

这套一共 200 多集、147 小时，**不要从头看**。在播放器右下角的"选集"里按标题搜，只挑下面这几段：

| 天 | 选集里搜这几个标题 | 看完要能回答 |
|---|---|---|
| 第 1 天 | 类与对象、成员变量与局部变量、方法 | 一个类里"字段"和"方法里的变量"有什么区别？为什么方法结束后变量就没了？ |
| 第 2 天 | 封装、构造器、this | 为什么 `new User()` 之后要给字段赋值？构造器是干什么的？ |
| 第 3 天 | 接口、多态 | `implements Filter` 到底承诺了什么？为什么必须实现 `doFilter`？ |

**练习**（每天 30 分钟，在 `jwt-lab` 里做）：

- 第 1 天：把 `TokenStore` 的 `save` / `getUsername` 抄到一个临时类里，改成实例方法（去掉 `static`），在 `main` 里 new 出来调用，打印结果
- 第 2 天：给 `User` 类加一个构造器 `User(String username, String password)`，把 `DataSeeder` 里的三行赋值改成一行 `new User("admin", hash)`
- 第 3 天：回答"`JpaRepository` 是接口还是类？为什么我们只写方法名就能用？"

**备选（觉得宋老师节奏慢）**：黑马 Java 零基础
<https://www.bilibili.com/video/BV17F411T7Ao>

**主课**：HTTP 协议精讲
<https://www.bilibili.com/video/BV1Mut7zEED7/>

这套偏架构，**只挑四集**：
- 03 浏览器发起 HTTP 请求的典型场景
- 12 详解 HTTP 的请求行
- 13 HTTP 的正确响应码
- 18 请求与响应的上下文

**第二课**：JavaWeb 里的过滤器部分
<https://www.bilibili.com/video/BV1Z3411C7NZ/?p=56>

看第 56、57 集（过滤器的使用与实现原理、责任链设计模式）。教的是 2021 年的写法，但**过滤器的位置和责任链的概念没变**，对照你写的 `AuthFilter` 看。

备选：尚硅谷 JavaWeb「什么是 Filter」
<https://www.bilibili.com/video/BV1Y7411K7zz/?p=293>

**看完要能回答**：

- 401 和 403 分别在什么情况下出现？

## 第 3 周：回项目做小改（每次 30 分钟）

不写新功能，只做小改动。**每次先预测结果，再运行验证。**

| 次数 | 改什么 | 先预测 |
|---|---|---|
| 1 | 把 403 改成 401（手写版 `AuthFilter`） | 浏览器打开 `/hello` 会看到什么？ |
| 2 | 把 `TokenStore` 的 TTL 改成 60 秒 | 登录后 61 秒再访问会怎样？ |
| 3 | 删掉 `JwtAuthFilter` 里的 `setAttribute` | `/me` 返回几？ |
| 4 | 给 `/me` 的返回加一个 `id` 字段 | 这个 id 从哪来？需要改几个文件？ |

预测错了，把"我以为/实际"写下来。这就是实感。

2. 每节后面有动手题

## 一个提醒

这些视频都是"看别人写"。真正的学习发生在你看完关掉视频、自己动手的那 30 分钟。看的时间不要超过动手的时间。总时长超过 60 分钟没动手的，那一节要重看。
